The full Routine Run story

What building it taught us

Four things you won't pay us to learn

Test the model on your task, not on a benchmark

Apple's on-device model writes a new routine from one sentence well. Asked to change an existing one, it mixed up steps in ways that were hard to notice. So in Routine Run, changes go to a bigger model. We test each task before we choose.

A hardware button should stay silent when it works

An action fired from the Action button or Control Center that pops a confirmation is a bug. Success is silent; only a failure speaks.

Don't ask for a face

Face ID came off five actions in Routine Run. If a step can be undone, asking for a face only adds a second of friction a hundred times a day.

Shortcuts caches your actions by build number

Change an intent and ship it under the same build, and people keep the old one. It's the kind of thing you learn once, on your own app, and never on a client's.

Questions

What people ask before they start

Do you work with existing apps, or only new ones?

Both. Most projects add AI, Siri or a Watch app to an app that already has users. We read your code first and say in the plan what we would change and what we would leave alone.

Our app is React Native or Flutter. Does this still work?

We build in Swift and SwiftUI. App Intents, the Watch and Apple's models are native APIs, so in a cross-platform app we add them as a native module. We'll tell you on the first call if that's the right path for your app.

Does Apple's on-device AI send our users' data anywhere?

The on-device model runs on the phone. Private Cloud Compute is Apple's server path with published privacy guarantees. If a task needs a third-party model, the plan says so and you decide.

What about older iPhones?

Apple Intelligence needs a recent iPhone. We design a fallback so people on older phones get a working screen, never a broken one.

Android?

Not today. The process design and the AI behind it carry over to Android; the Apple layer is native to Apple.

Who owns the code?

You do, from the first commit, in your repository and your Apple developer account.
